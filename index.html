Data Science Data Analyst Data Engineering Calcul scientifique

Data Scientist stagiaire : IA multimodale & analyse de données pour la prédiction de propriétés de matériaux

avril à juillet 2026 (6 mois)
Laboratoire L2MGC, CY Cergy Paris Université · Neuville-sur-Oise
  • J'ai commencé par collecter automatiquement 388 articles scientifiques avec Python (API CrossRef, web scraping), puis à structurer cette matière première en base exploitable.
  • Ensuite, j'ai nettoyé, fiabilisé et analysé 2 297 formulations (43 variables) et 483 images MEB/BSE, avec stockage et requêtage SQL.
  • J'ai fait du feature engineering : segmentation multi-Otsu, matrices GLCM, et un caption-matching qui a associé automatiquement 141 images à leur formulation (+86 % de données exploitables).
  • J'ai développé une approche multimodale qui combine données tabulaires et images microscopiques pour prédire la résistance mécanique du béton.
  • J'ai benchmarké 6 modèles de machine learning en validation croisée. XGBoost est ressorti meilleur, avec un R² = 0,76 et un MAE < 10 MPa.
  • J'ai enfin travaillé l'interprétabilité (t-SNE, Grad-CAM) et restitué les résultats aux chercheurs.
Python · pandas · NumPy · scikit-learn · PyTorch · XGBoost · OpenCV · API CrossRef · JSON · web scraping · SQL · Git
