Expérience

Ce que j'ai fait concrètement

Data Scientist stagiaire : IA multimodale & analyse de données pour la prédiction de propriétés de matériaux

avril à juillet 2026
Laboratoire L2MGC, CY Cergy Paris Université · Neuville-sur-Oise
  • J'ai collecté automatiquement 388 articles scientifiques avec Python (API CrossRef, web scraping), puis structuré cette matière première en base exploitable.
  • J'ai nettoyé, fiabilisé et analysé 2 297 formulations (43 variables) et 483 images MEB/BSE, avec stockage et requêtage SQL.
  • J'ai fait du feature engineering (segmentation multi-Otsu, matrices GLCM) et un caption-matching qui a associé automatiquement 141 images à leur formulation. Le pipeline a augmenté de 86 % le volume de données exploitables.
  • J'ai développé une approche multimodale combinant données tabulaires et images microscopiques pour prédire la résistance mécanique du béton.
  • J'ai comparé 6 modèles en validation croisée (XGBoost, Random Forest, MLP, ResNet18, fusion multimodale) : XGBoost est ressorti meilleur, avec R² = 0,76 et MAE < 10 MPa.
  • J'ai travaillé l'interprétabilité (t-SNE, Grad-CAM) et restitué les résultats aux chercheurs.
Python · pandas · NumPy · scikit-learn · PyTorch · XGBoost · OpenCV · API CrossRef · SQL · Git
